# show-projects

Витринные Android-демки для LinkedIn: короткие эффектные штуки на Jetpack Compose.
Каждый проект — отдельная папка со своим Gradle-проектом.

| Проект | Что это |
|---|---|
| [lift](lift/) | «Оторвать» объект от фото долгим нажатием, как Lift Subject в iOS, и сделать из него стикер |
| [holo-card](holo-card/) | Compose Bank — мини-банк с металлическими картами: AGSL-голограмма от наклона телефона, переворот свайпом, заморозка инеем, оплата с волнами |
